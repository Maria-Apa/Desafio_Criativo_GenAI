# Desafio Criativo com GenAI: Extraindo Insights do Feedback de Clientes Bancários

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio **"Desafio Criativo com GenAI: Extraindo Insights do Feedback de Clientes Bancários"** da DIO.

O objetivo é demonstrar como a Inteligência Artificial Generativa pode ser utilizada para analisar feedbacks de clientes e identificar oportunidades de melhoria em produtos financeiros.

Para isso, foi criado um conjunto de dados fictícios representando clientes, produtos bancários e feedbacks. Após o tratamento dos dados, foi desenvolvido um prompt especializado para que o ChatGPT realizasse análises e gerasse recomendações estratégicas com base nas informações fornecidas.

Os insights obtidos podem auxiliar equipes de produtos e experiência do cliente a identificar problemas recorrentes, aprimorar serviços existentes e orientar o desenvolvimento de novas soluções financeiras.

---

## 🎯 Objetivos

* Simular um ambiente de análise de feedbacks de clientes bancários.
* Aplicar técnicas de tratamento e preparação de dados.
* Utilizar IA Generativa para extração de insights.
* Identificar pontos de melhoria em produtos financeiros.
* Apoiar a tomada de decisão baseada em dados.
* Demonstrar conhecimentos em Power Query, manipulação de dados e engenharia de prompts.

## 📊 Base de Dados

Foram criados três arquivos JSON contendo dados fictícios para simular um ambiente bancário:

### clientes.json

Contém informações cadastrais dos clientes.

### produtos.json

Contém informações sobre os produtos financeiros oferecidos.

### feedbacks.json

Contém avaliações, comentários e opiniões dos clientes sobre os produtos contratados.

---

## 🔄 Tratamento dos Dados

Após a criação dos arquivos JSON, os dados foram importados para o Power Query, onde foram realizadas etapas de tratamento e padronização, incluindo:

* Ajuste de nomenclaturas;
* Padronização de campos;
* Correção de inconsistências;
* Organização das informações para análise;
* Preparação da base para consumo pela IA.

O resultado desse processo foi consolidado no arquivo:

* Feedbacks_clientes.xlsx

---

## 🤖 Uso da Inteligência Artificial

Foi desenvolvido um prompt específico para orientar o ChatGPT na análise dos dados.

O modelo foi instruído a:

* Identificar padrões nos feedbacks;
* Encontrar pontos de melhoria dos produtos;
* Detectar necessidades recorrentes dos clientes;
* Comparar feedbacks entre produtos semelhantes;
* Sugerir oportunidades para criação de novos produtos ou melhorias nos existentes.
