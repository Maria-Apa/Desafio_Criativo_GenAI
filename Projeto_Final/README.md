# Desafio Criativo com GenAI: Extraindo Insights do Feedback de Clientes Bancários

Realizei a criação de um projeto para um desafio criativo, onde desenvolvir um prompt para que o chatGPT analise um arquivo Excel (Que eu mesmo desenvolvir) e me mostre pontos de melhoria de acordo com os feedbacks dos clientes, esses pontos de melhoria seriam tilizadfos pelo setor identificar o que melhorar nos produtos antes de oferecer novas variedades. 

Para desenvolvimento do projeto, criei 3 documentos em json que são: clientes.json, feedbacks.json e produtos.json. Cada arquivo possui dados a serem analisados para captação de mais informações. 

Com os dados json em mãos, realizei o tratamento de dados utilizando o Power Query e alterei algumas infromações para que ficasse mais entendivel as informações, após os dados estarem prontos realizamos a criação do Prompts para que o ChatGPT possa analisar e reizar recomendações sobre os pontos de melhoria. 

O Projeto possui a seguinte Main:

Docs - cliente.json, feedbacks.json, produtos,json.
Projeto_Final, READM.md, prompts, Analise_chat.
Tratamento_dados, Feedbacks_clientes.xlsx
Visualização_Projetos
